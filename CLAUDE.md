## Ловушки, которые уже стоили времени
- **Кодировка.** `.mod`, `steadystate.m` и часть `.m` в **cp1251 с CRLF**. Инструмент Edit и запись без указания кодировки портят русские комментарии. Правьте только через Python: `io.open(f, encoding='cp1251', newline='')`, каждая замена с проверкой на единственность вхождения, образец — `tools_make_T2_1.py`.
- **Бинарников нет.** `dynare-5.4/mex/` и `dynare-5.4/preprocessor/` в репозиторий не входят (Windows-бинарники, 111 МБ). На Windows скопируйте их из официального Dynare 5.4 (`D:\dynare\5.4`). В облачной Linux-сессии MATLAB и эти mex не работают: там можно править код, писать документацию и рассчитывать вне Dynare.
- **Дефект правленой сборки.** При нарушении условия Бланшара-Кана `dyn_first_order_solver.m` (строка 265) падает вместо возврата `info=3/4`; перебор параметров нужно оборачивать в try/catch.
- **Пакетный MATLAB на Windows.** Команду кладите в файл и вызывайте `matlab -batch "run('файл.m')"`; `Start-Process` не берёт в кавычки аргумент с пробелами и молча выходит с кодом 0.
- **`model_T3_0`.** Стартовые значения в `estimated_params` (например `b_WH_SS=0`) ломают стационар; работает только с `mode_file`, собранным из `model_T3_temp_full.mat`.
